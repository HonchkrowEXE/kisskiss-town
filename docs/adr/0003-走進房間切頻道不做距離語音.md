# 走進語音房由 bot 搬頻道，不做距離語音

Discord Activity 不支援 WebRTC（docs.discord.com/developers/activities/development-guides/networking），Embedded App SDK 也控制不了麥克風、沒辦法讓人加入語音。所以做不到 gather.town 那種「越靠近越大聲」的距離語音。改成：房間綁定一個 Discord 頻道，成員走進語音房時，bot 用 Move Members 把他搬過去（前提是他已經在語音裡）。

## Consequences

- 小鎮的狀態以 Discord 伺服器為單位存在我們的後端，不能依附在 Activity 的 instance 上，因為 Discord 每個頻道各開一份 instance。
- 成員被搬到其他頻道後，Activity 畫面會不會斷掉，文件沒寫，要先實測。
- 「誰在直播」（`self_stream`）SDK 拿不到，要由 bot 監聽語音狀態再轉給前端。
