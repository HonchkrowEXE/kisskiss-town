# 匯入地圖照 tilemap.dev 與 Tiled 的慣例判斷碰撞、出生點、房間

管理員匯入的自訂地圖（#5）覆蓋自動長出來的小鎮（ADR-0010），不另外做標牆的編輯器，直接讀地圖檔裡已經有的資訊：

- **牆**：以下任何一種都算（程式在 `town/walkable.ts`）
  - 圖塊集裡標了 `collides: true` 的圖塊（Tiled 的慣例，自動長出來的小鎮也用這個）
  - 名稱是 `Collision` 的圖塊層，或有 `collidable: true` 屬性的圖塊層：有放圖塊的格子（tilemap.dev 會產生隱藏的 Collision 圖層；這層不畫出來）
  - 名稱是 `Colliders` 的物件層，或有 `collidable: true` 屬性的物件層：矩形蓋到的格子（tilemap.dev 的 Colliders 群組）
- **出生點**：`Spawn Points` 物件層裡的物件（tilemap.dev），或名稱、class 是 `spawn` 的物件；都沒有就用地圖中央
- **房間**：class（或 type）是 `area`、有 `channel` 屬性的矩形物件，`channel` 填頻道 ID 或頻道名稱（ADR-0006 的格式）。頻道不在清單裡（例如私人頻道）就不算

## Considered Options

- **在 Activity 的編輯模式裡標牆**：要做一個圖塊編輯器，ADR-0006 已經決定不自己寫。
- **只認固定名稱的碰撞圖層**：Tiled 使用者習慣用圖塊屬性標牆，只認圖層名會讓他們的地圖沒有牆。

## Consequences

- 一張地圖用多種方式標牆也可以，全部合起來算。
- 只支援方形格子、非無限、圖塊層是 CSV 格式、圖塊集嵌在地圖裡（Embed tilesets）的地圖；不符合時匯入畫面會說明怎麼在 Tiled 改。
- 自訂地圖連圖片存在資料庫，也整份同步給前端，所以限制大小（200 × 200 格、上傳 8 MB）。
