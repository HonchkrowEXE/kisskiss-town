# 資料存在 Node 內建的 SQLite（`node:sqlite`）

籌碼帳本、各伺服器的地圖、房間設定都要存下來。第一版用 Node 內建的 `node:sqlite`（Node 22.5 起內建，專案要求 Node 22 以上），一個檔案就是整個資料庫，不另外裝套件，也不用另外架資料庫服務。

理由：Colyseus 現在是單一程序，所有寫入都在同一個程序裡，SQLite 的同步 API 不會有交錯寫入的問題；規模是「每個 Discord 伺服器一座小鎮」，資料量很小。部署時只要一塊會保留的磁碟放資料庫檔。

之後如果 Colyseus 要開多個程序或多台機器，再換成 Postgres。存取都包在各自的模組裡（例如籌碼帳本），換資料庫時只改那幾個模組。
