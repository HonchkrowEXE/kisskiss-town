# 角色用 LPC 部件組成，照片由 AI 判斷特徵後自動挑部件

成員上傳照片，Claude API 以結構化 JSON 回傳特徵（髮型、髮色、膚色、衣服顏色、眼鏡等），再從 Universal LPC 部件庫挑最接近的部件組合。動畫直接沿用部件本身的走路動畫（64×64，4 個方向）。

## Considered Options

- **只把頭像素化，接在共用身體上**：頭很難轉向。
- **AI 直接產生整套動畫圖**：不同方向、不同動畫格之間的長相很難保持一致，每張圖也要付費。

## Consequences

- LPC 素材每張圖的授權不同，除了 CC0 都要標作者，遊戲裡要有製作名單頁（作者資料來自 LPC 的 `CREDITS.csv`）。
- 照片會送到 Anthropic 處理（預設 30 天內刪除），上傳畫面要告知使用者。照片審核之後再做。
