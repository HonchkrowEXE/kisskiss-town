# 小鎮從 Discord 頻道清單自動長出來，匯入地圖延後

親親小鎮的核心是「把 Discord 伺服器畫成看得到的地方」。原本的做法（ADR-0006）要管理員先用 tilemap.dev 畫圖、匯入、再框房間綁頻道，打開 Activity 之前要做很多事。

改成：伺服器讀取 Discord 的頻道清單，每個語音頻道和文字頻道自動變成地圖上的一個房間，房間上寫頻道名稱，排列順序跟 Discord 的頻道順序一致。頻道新增、刪除、改名時，小鎮跟著變。管理員什麼都不用做。

頻道清單透過 bot 讀取，並經過平台轉接層（ADR-0008）。

匯入自訂地圖（ADR-0006、#5）延後，等之後想讓小鎮更漂亮再做；到時候自訂地圖是覆蓋在自動版之上的選項，不是必要步驟。
