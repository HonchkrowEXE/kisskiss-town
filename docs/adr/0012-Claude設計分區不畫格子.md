# Claude 設計小鎮時只決定分區，不畫格子

管理員可以寫一段描述（例如「像一間咖啡廳，語音房放前面」），請 Claude 重新設計小鎮。

Claude 只回傳**分區規劃**：每區的名稱、裡面有哪些頻道（用清單上的編號）、房間大小（小、中、大）、地板樣式。程式再用 `layoutTown` 照規劃畫出地圖。不讓 Claude 直接輸出 Tiled 的格子資料，原因：

- **一定畫得出來**：門、走道、碰撞都由同一套程式產生，不會有走不進去的房間。
- **輸出很短**：500 個頻道的伺服器也只要幾千個 token，回得快、比較不會被截斷。
- **頻道變了還能用**：規劃存的是頻道 ID；之後新增的頻道自動放到「其他」區，刪掉的頻道自動略過，不用重新設計。

代價是 Claude 不能做出規則以外的形狀（例如圓形廣場、斜的走廊）。想要那種地圖，就把目前的地圖匯出成 Tiled 格式自己改，再匯入（ADR-0011 的慣例）。

沒有選過地圖的新伺服器，先用照 Discord 分類自動分區的地圖（ADR-0010），管理員第一次進來會跳出選地圖的畫面。
